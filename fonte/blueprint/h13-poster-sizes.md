# Poster sizes and bleed checklist
Checked 5 Oct 2026. Sources are at the bottom. Ask your printer first. Some want more bleed or a different file type.

## The rule in one line
Build the file at trim size plus bleed. Keep every word inside the safe margin.

- Trim: the final size after the poster is cut.
- Bleed: extra art past the trim, so no white edge shows. Add 0.125 in (3 mm) on all four sides.
- Safe margin: keep text and logos at least 0.25 in (6 mm) inside the trim.

## Print sizes, ISO A series, at 300 dpi
Pixels = inches x 300. The file size is the trim plus 3 mm on each side.

| Size | Trim (mm) | Trim in pixels | File with bleed (mm) | File in pixels |
|------|-----------|----------------|----------------------|----------------|
| A4 | 210 x 297 | 2480 x 3508 | 216 x 303 | 2551 x 3579 |
| A3 | 297 x 420 | 3508 x 4961 | 303 x 426 | 3579 x 5031 |
| A2 | 420 x 594 | 4961 x 7016 | 426 x 600 | 5031 x 7087 |
| A1 | 594 x 841 | 7016 x 9933 | 600 x 847 | 7087 x 10004 |
| A0 | 841 x 1189 | 9933 x 14043 | 847 x 1195 | 10004 x 14114 |

## Print sizes, US, at 300 dpi
The file size is the trim plus 0.125 in on each side.

| Size | Trim in pixels | File with bleed (in) | File in pixels |

## Social sizes
| Where | Ratio | Size | Note |
|-------|-------|------|------|
| Instagram feed | 4:5 | 1440 x 1800 px | Meta's size for feed image ads. JPG or PNG. |
| Instagram Story | 9:16 | 1440 x 2560 px | Keep the top 14%, the bottom 35% and the sides 6% free of text. |
| Pinterest Pin | 2:3 | 1000 x 1500 px | Taller than 2:3 may get cropped. |

A print poster is not a social post. Make a separate crop for each place. Do not reuse the print safe margin.

## Before you send it
- [ ] The file is trim plus bleed in size.
- [ ] Art runs to the edge of the bleed. No white strip.
- [ ] All text sits 6 mm (0.25 in) inside the trim.
- [ ] Fonts are embedded in the PDF.
- [ ] Photos are 300 dpi at the final size. For a large poster, 150 to 250 dpi is fine.
- [ ] Colour: printers ask for CMYK. Ask yours to convert, or convert before you send. Expect small shifts.
- [ ] File type is PDF. It keeps layout and fonts.
- [ ] You looked at a proof, or a small test print.
- [ ] Each social crop is made for its own place.
